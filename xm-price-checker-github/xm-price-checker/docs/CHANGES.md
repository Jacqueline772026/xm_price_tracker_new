# 本次改动说明 / Change notes (2026-11-07)

原始文件已备份在上一级目录：`XM_Price_Checker-main_backup_*`。

## 1. 修复 MSH (MediaMarkt) 抓不到
- 原因：页面把商品卡属性 `data-test="mms-product-card"` 改名为 `mms-cofr-product-card`，旧选择器找到 0 张卡，
  scraper 返回空列表，Notebook 对空结果只 `continue`，所以 MSH 整列空白且不报错。
- `scrapers/msh.py`：新旧选择器都接受；先等待商品卡出现；0 张卡且没有“无结果”提示时报错（Notebook 会记一条 ERROR），
  遇到验证/拦截页面则停止（不绕过）。

## 2. MSH 匹配逻辑加强（`scrapers/matching.py` 新增，纯函数，可单独测试）
- 型号：目标词必须连续出现，中间只允许 smartfon/tablet/xiaomi/5g/4g/lte/gb 这类词。
  以前允许任意词夹在中间，目标 “Redmi 17” 会匹配 “Redmi Note 17”。
- 官方店：沿用原规则——出现 “Sprzedaż i wysyłka przez XX” = 非官方，丢弃；没有卖家字样 = 官方店。
  （额外：卡片带第三方卖家页链接也视为非官方，这种卡片同时都有卖家字样，结果与原规则一致。）
- 价格：只读现价区块；不再读划线参考价（“Najniższa cena: …”）和分期价（“…zł miesięcznie”）。
- 库存：读 MediaMarkt 自己的配送状态（AVAILABLE / NOT_AVAILABLE），文字作后备。

## Links generated by program (link_builder.py)

- `link_builder.py` builds every search link from the Products sheet (name + RAM/storage) using one rule per site (MEX, Electro.pl, Avans, MSH, KTR, XKOM, NEONET, Max electro).
- `python link_builder.py check "<workbook>.xlsm"` compares the Links sheet with the generated links (never writes the workbook).
- `python link_builder.py new "<workbook>.xlsm" <TargetID> [--sites MEX,MSH]` prints ready-to-paste rows (also saved as CSV).
- `link_overrides.json` keeps the 31 hand-tuned search texts that were already in use.
- `price_checks.py` now flags a link that differs from the generated one (`link-differs`, MEDIUM) — this catches the old 8+512 -> 8256 / 6256 typos.
- Official-shop rule on MSH reverted: no seller line = official.
- Bracket encoding (`[ ]` vs `%5b %5d`) in 5 override links is harmless.
- `euro.py` is unfinished (Euro blocks bots), has no Links, and is not used; left untouched.

## 2026-11-10 (later) – KTR availability, RRP ignored, rm = Redmi
- **KTR**: availability was "Unknown" for most cards. Komputronik writes "Produkt dostepny w magazynie" (no accent), "Wysyłamy/Wysyłka najczęściej…", "Produkt wysyłamy z salonu", "Czekamy na dostawę towaru"; unavailable cards say "Produkt tymczasowo niedostępny. Powiadom o dostępności". The old code only looked for "dostępny"/"dodaj do koszyka", and "niedostępny" even contains "dostępny". Now `ktr.classify_availability` (accent-free, unavailable markers first). Checked on 130 live cards: 0 Unknown.
- **Only the promotion price is the reference.** RRP is ignored: no "promo above RRP" / "above RRP" findings. New `far-above-promo` (> promo +30%, MEDIUM).
- `same-colour-prices` is LOW (Results lists every different price).
- `link-name` check understands `rm` = Redmi. New `tests/test_ktr.py`; 52 tests.
- **Same text rules for every shop**: `matching.classify_availability` (accents removed, "unavailable" first) is used by KTR, MEX, XKOM, AVANS, NEONET, Max Elektro. Back-order ("Czekamy na dostawę") = Unavailable. Live-checked: 0 unreadable cards on all of them.
- **Colours**: `matching.detect_colour` (EN + PL + marketing names) is the fallback of every `get_color`.
- **MEX**: card without price and without buy block = Unavailable.
- **Page-change alarm**: >=30% unreadable stock status on one site -> HIGH `layout-changed` in the report.
- **Editable wording list**: `availability_markers.json`; unreadable cards go to `unknown_availability.log`, and the `layout-changed` alarm prints them in the check report.
