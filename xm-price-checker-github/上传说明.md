# 上传到 GitHub 的步骤

## 先确认(重要)
1. **授权**:这个工具的原作者是同事 Garlie Li,里面还有零售网站的抓取逻辑。公开前请先和同事、公司确认可以放到 GitHub。
2. **建议先用 Private(私有)仓库**,只给内部同事权限。
3. 仓库里**没有**真实价格和历史数据:`templates/` 下的模板已清空价格、日期和 RawData;`.gitignore` 会挡住 `*.xlsm`。但模板里保留了机型清单(含内部代号)和零售商搜索链接,如果这些也不想外露,请保持私有仓库。
4. 已检查:仓库文本和模板文件里没有邮箱、本机路径或密钥。

## 方法一:网页上传(最简单)
1. GitHub → New repository → 名称如 `xm-price-checker` → 选 Private → 不要勾选 README/.gitignore/License → Create。
2. 点 "uploading an existing file",把 `xm-price-checker` 文件夹里**所有内容**拖进去(注意包含隐藏文件夹 `.github` 和 `.idea`;Mac 在 Finder 里按 Cmd+Shift+. 显示隐藏文件)。
3. Commit changes。

## 方法二:命令行(推荐,能保留隐藏文件和可执行权限)
```bash
cd xm-price-checker
git init -b main
git add .
git status            # 确认没有 .xlsm(除 templates/ 下的模板)、没有 .venv
git commit -m "Initial import: XM Price Checker"
git remote add origin https://github.com/<你的账号或组织>/xm-price-checker.git
git push -u origin main
```
用 GitHub CLI 也可以:`gh repo create xm-price-checker --private --source=. --push`

## 上传之后
- 仓库的 Actions 页会自动跑一次离线单元测试(`.github/workflows/tests.yml`)。
- 同事使用:`git clone` → 照 README 的"快速开始"做(复制模板为 `XM_Price_Checker_Python.xlsm` 再填价格)。
- 每周的真实价格表放在自己电脑上,**不要提交**。
